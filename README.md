# cli-dj (visual-only prototype)

ghostty風にペイン分割したターミナルDJアプリの見た目プロトタイプ。
**音は一切鳴りません** — 波形・BPM・キューは全部フェイクデータで、レイアウトとコマンド言語の使い心地を確かめるためのモックです。

```
+-----------+-----------------------------+
|           |          CONSOLE            |
|  LIBRARY  |------------------------------
|           |          DECK A              |
|           |          DECK B              |
+-----------+-----------------------------+
```

## 起動

```bash
pip install -r requirements.txt
python app.py
```

## コマンド

右上のコマンドラインに入力してEnter。`a`/`b`が各デッキ。

```
a.load(3)        ライブラリの#3をデッキAにロード
a.play()         a.pause()        a.stop()
a.cue(1)         キューポイント1-4へジャンプ
a.loop(128, 160) 128拍目〜160拍目(トラック先頭からの拍数)でループ
a.loop()         ループ解除
b.sync()         このデッキのテンポをもう一方のデッキに合わせる
b.unsync()       元のBPMに戻す
xfade(0.5)       クロスフェーダー移動 (0=A, 1=B)
clear()          ログをクリア
help()           コマンド一覧
```

## 実装メモ

- `library.py` — フェイクの曲データ(タイトル/BPM/キー)と、曲ごとにシードから生成した波形・キューポイント
- `models.py` — デッキの再生状態(位置・再生中/停止・ループ・シンク)。実オーディオなしのシミュレーション
- `commands.py` — `a.play()` のような関数呼び出し風コマンドをパースして実行
- `app.py` — Textual製のTUI本体。波形はUnicodeブロック文字(`▁▂▃▄▅▆▇█`)で1行に疑似レンダリング
