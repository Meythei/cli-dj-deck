# 聴感チェックリスト

自動テストは「どこで鳴り始めるか」「長さ」「クリックの有無(サンプル差分)」「帯域のエネルギー」などを数値で
確認していますが、**クロスフェードの自然さ・ループの継ぎ目・タイムストレッチの質** のように耳で判断するしか
ないものが残ります。このチェックリストはその確認用です。開発者(Claude)は音を聴けないため、ここに書いた
「数値で確認済み」の項目以外は未確認です。

## 準備

```bash
.venv\Scripts\python scripts\render_listening.py
```

`renders\listening\` に 7 本の WAV(48kHz / 24bit)ができます(1〜2分)。音源はデモライブラリの合成音
(キック・オフビートのハット・ベース・コードの単純なテクノ)で、毎回同じ内容です。小節番号は 4/4 で、
`128 BPM なら 1小節 = 1.875 秒` です。できればヘッドホンか低域の出るスピーカーで聴いてください。

問題があったら、ファイル名・小節・聞こえ方(例:「03 の 13小節目からキックの頭がぼやける」)をメモしてください。

## 01_crossfade.wav(20小節・128 BPM)

L1 = デモ曲1のドロップ(マイナーのコード)、L2 = デモ曲5のドロップ(メジャーのコード)。5小節目の頭から 8小節かけて
L1 → L2 に直線でクロスフェードし、13小節目の頭で L1 が止まります。

| 小節 | 聞こえるはずのもの | 失敗の例 |
|---|---|---|
| 1-4 | L1 だけ | |
| 5 の頭 | L2 がほぼ無音から入り始める。キックは1つに揃ったまま | キックが二重(フラム)に聞こえる、頭でプツッと鳴る |
| 5-12 | コードがマイナーからメジャーへ徐々に入れ替わる。全体の音量はほぼ一定 | 途中で音量が明らかに凹む/膨らむ、揺れる |
| 13 の頭 | L1 の音が残っていない。切れ目が分からない | 13 小節目の頭で音が途切れる・クリック |
| 13-20 | L2 だけ | |

- [ ] キックが最後まで1つに揃っている
- [ ] フェードの途中で音量が不自然に変わらない
- [ ] 5 / 13 小節目の頭にノイズがない

数値で確認済み: 小節ごとの RMS は -13.1〜-14.2 dB(フェード中の凹みは最大 0.6 dB)、5・13 小節目の前後 10ms の最大サンプル差分 0.015(ファイル全体の 99.9 パーセンタイルは 0.233)。

## 02_loop_seams.wav(16小節・128 BPM)

1-8 小節: デモ曲1の **1小節** をループ(= 8回繰り返す)。9-16 小節: デモ曲3(130 BPM → 128 BPM にストレッチ)の **2拍** をループ(= 16回繰り返す)。

| 小節 | 聞こえるはずのもの | 失敗の例 |
|---|---|---|
| 各小節の頭(1-8) | ループの継ぎ目が分からない。キックの頭がそのまま | 継ぎ目ごとにプツッ・コツッという音、キックの頭が欠ける/ダブる |
| 9 の頭 | L1 が止まり L2 が入る | 切り替えでクリック |
| 9-16 の2拍ごと | 継ぎ目で音色やレベルが跳ねない | 周期的なクリック、2拍ごとに「息継ぎ」のような凹み |

- [ ] 1小節ループの継ぎ目(8か所)が聞き取れない
- [ ] 2拍ループの継ぎ目(16か所)が聞き取れない

数値で確認済み: すべての継ぎ目の前後 2ms の最大サンプル差分 0.011(ファイル全体の最大は 0.504)。

## 03_stretch_quality.wav(16小節)

デモ曲3(元 130 BPM)のドロップ4小節を、4小節ごとに違う BPM でループします。BPM は途中で `bpm()` を打った
ことにしてあり、新しい BPM のレンダリングが済んだ後の小節頭で切り替わります。

| 小節 | BPM | 元からの変化 |
|---|---|---|
| 1-4 | 130 | なし(ストレッチなし) |
| 5-8 | 122 | -6% |
| 9-12 | 140 | +8% |
| 13-16 | 150 | +15% |

| 確認すること | 失敗の例 |
|---|---|
| ピッチ(音の高さ)が 4区間で変わらない | テンポと一緒に音程が上下する |
| キックのアタックがはっきりしている | 「ボワッ」と頭がにじむ、アタックが二重 |
| ベースが揺れない・濁らない | うなり、金属的な響き、低音がぼやける(短い FFT 窓を使っているため低域が一番の懸念。docs/decisions.md D7) |
| ハットがシャリシャリしすぎない | 残響のような尾、フェイザーのような揺れ |
| 区間の切り替え(5・9・13 小節目の頭)が滑らか | 切り替えでつんのめる/詰まる、クリック |

- [ ] 122 BPM(-6%)で違和感がない
- [ ] 140 BPM(+8%)で違和感がない
- [ ] 150 BPM(+15%)は DJ でふだん使わない変化量。どこから気になるかをメモ
- [ ] 低域(キック・ベース)の質が許容範囲

数値で確認済み: 各区間の実測テンポ 129.96 / 121.95 / 139.68 / 149.91 BPM(ビートグリッド推定)。

## 04_eq_isolator.wav(16小節・128 BPM)

デモ曲8のドロップを流しながら、2小節ごとに EQ(アイソレータ)を切り替えます。

| 小節 | 設定 | 聞こえるはずのもの |
|---|---|---|
| 1-2 | すべて 1 | 元の音 |
| 3-4 | lo=0 | キックとベースの低音が抜ける(ハット・コードは残る) |
| 5-6 | lo=1, mid=0 | 低音が戻り、コードの中音域が抜ける |
| 7-8 | mid=1, hi=0 | ハットのシャリシャリが消える(こもった音) |
| 9-10 | hi=1 | 元の音 |
| 11-12 | すべて 0.3 | 全体に約 -10dB 小さく、音色は元のまま |
| 13 | すべて 1 | 元の音 |
| 14 の3拍目 / 4拍目 | `L1.gain(0.2)` → `L1.gain(1.0)` | 瞬時に音量が下がって戻る |
| 15 の3拍目 / 4拍目 | `L1.mute()` → `L1.unmute()` | 瞬時に消えて戻る |

- [ ] 各切り替えで「プツッ」「ジジッ」(ジッパーノイズ)がない(5ms で平滑化している)
- [ ] lo=0 で低音が十分に消える(DJ ミキサーのキルとして使えるか)
- [ ] 帯域の境目(250Hz / 2.5kHz 付近)で音が不自然に凹まない(すべて 1 のときは平坦なはず)

数値で確認済み(帯域別 RMS): 3-4小節の低域 -41.6 dB(元 -13.6)、5-6小節の中域 -53.2 dB(元 -37.3)、7-8小節の高域 -76.3 dB(元 -39.0)、11-12小節は約 -10.4 dB。

## 05_tempo_change.wav(16小節)

L1 = デモ曲1のドロップ(ドラム)、L2 = デモ曲8のドロップ(ベース)。セットの最初に `prep()` し、
`at(5, bpm(132))` `at(9, bpm(124))` `at(13, bpm(128))` で BPM を変えます。

| 小節 | BPM | 確認すること |
|---|---|---|
| 1-4 | 128 | |
| 5 の頭 | → 132 | 切り替えの瞬間に途切れ・二重打ち・クリックがない。2レーンのずれがない |
| 9 の頭 | → 124 | 同上 |
| 13 の頭 | → 128 | 同上 |

- [ ] 3回の切り替えが「その小節から速さが変わった」とだけ感じられる
- [ ] L1 と L2 が最後まで揃っている

数値で確認済み: 各区間の実測テンポ 127.95 / 131.93 / 124.13 / 128.01 BPM、各切り替えの前後 10ms の最大サンプル差分 0.005〜0.016(ファイル全体の 99.9 パーセンタイルは 0.307)。

## 06_replace_and_stop.wav(12小節・128 BPM)

| 小節 | 操作 | 聞こえるはずのもの |
|---|---|---|
| 1-2 | L1 << a(曲1) | |
| 3 の頭 | L1 << b(曲6、132 → 128 BPM) | 同じレーンで別のループに瞬時に差し替わる |
| 5 の頭 | L1 << a、L2 << riser(曲4、122 → 128 BPM、ループなし2小節) | a に戻り、riser が重なる |
| 7 の頭 | L1.stop()(riser もここで終わる) | 音が止まる |
| 8 | | 無音 |
| 9 の頭 | L1 << b | 再び鳴る |
| 10 の3拍目 | `stop()` → すぐ `start()` | 一瞬止まって同じ位置から再開(ファイル上は止まっていた時間は詰まる) |

- [ ] 3・5・9小節目の差し替えでクリックがない(差し替えは 5ms のクロスフェード)
- [ ] 7小節目の停止がブツッと切れず自然
- [ ] riser の終わり(7小節目の頭)で余韻が不自然に切れない(非ループのスニペットは末尾 3ms でフェード)
- [ ] 10小節目の stop/start でクリックがない

数値で確認済み: 8小節目はデジタル無音、3・5・7・9小節目の頭の前後 10ms の最大サンプル差分 0.011〜0.018。

## 実デバイスでの確認(リアルタイム再生)

WAV とは別に、実際に TUI からスピーカーで鳴らして確認してください。

```bash
.venv\Scripts\python -m clidj --demo --set sets/demo.djs
```

1. 起動直後の AUDIO 行にデバイス名と `lat` が出る。デモ曲の合成とレンダリングが終わるまで(初回は数十秒)L1 が「waiting for render」になる
2. `start()` → 上の 07 と同じ展開がスピーカーから鳴る
3. 演奏中に `L2.eq(lo=0)` → 即座に L2 の低音が抜ける
4. 演奏中に `at(20, L3.stop())`、`after(1, L2 << drop)`、`every(4, L4.mute())` などを打つ → 指定の小節頭ちょうどで起きる
5. 演奏中に `bpm(132)` → レンダリング後の小節頭で切り替わる(ヘッダに予定の小節が出る)
6. 10分ほど流して、AUDIO 行の `xrun` と `late` が 0 のまま
7. 画面の ▼ と実際に聞こえるキックが揃っている(ずれていれば `docs/decisions.md` にメモ。表示は出力レイテンシとリミッタの遅延を差し引いた位置)
8. `quit()` か Ctrl+C で終了し、タスクマネージャーに python のプロセスが残っていない

- [ ] 1〜8 すべて問題なし
